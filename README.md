# My-Python-Learning-Journey

Python 课程第 1 次平时作业：我的第一个 GitHub 仓库。

## 项目内容

俄罗斯方块（Tetris）小游戏。用 Python 写了两个版本，游戏逻辑完全一致，区别只在渲染与输入层：

| 文件 | 依赖 | 说明 |
| --- | --- | --- |
| `tetris.py` | pygame | 基于 pygame 的图形版本，画面更细腻 |
| `tetris_tk.py` | 无（标准库 tkinter） | 零第三方依赖版本，装了 Python 就能跑 |

## 功能

- 7 种标准方块，7-bag 随机（每 7 个方块内每种各出现一次，不会连着来一堆积木）
- 四向旋转，带简易墙踢（贴墙、贴地旋转时自动让位）
- 半透明落点预览、下一个方块预览
- 消行计分：1/2/3/4 行 → 100/300/500/800 × 当前等级
- 每消 10 行升一级，下落速度随之加快
- 暂停、重新开始、游戏结束判定

## 运行

零依赖版本（推荐）：

```bash
python tetris_tk.py
```

pygame 版本：

```bash
pip install pygame
python tetris.py
```

## 操作

| 按键 | 作用 |
| --- | --- |
| ← / → | 左右移动（长按连发） |
| ↓ | 软降 |
| ↑ 或 X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降 |
| P | 暂停 / 继续 |
| R | 重新开始 |
| Esc | 退出 |

## 代码结构说明

两个文件都采用「游戏逻辑与界面分离」的写法：

- `Tetris` 类只负责棋盘状态：方块生成、碰撞检测、旋转墙踢、锁定、消行、计分、等级
- 界面层只负责把状态画出来、把按键翻译成操作

所以 `tetris.py` 和 `tetris_tk.py` 里的 `Tetris` 类几乎完全相同，换掉渲染层就是一个新版本。
